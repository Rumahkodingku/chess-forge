# R6 Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** Execute `docs/specs/R6-export.md` end to end on `main`.

**Architecture:** Add pure export configuration, capability, and validation helpers, then route the existing Remotion web renderer through a validated snapshot pipeline and a richer studio Export card.

**Tech Stack:** Next.js App Router, React, TypeScript, Zod, Remotion web renderer, Mediabunny, Vitest, Playwright, ffprobe.

**Spec:** `docs/specs/R6-export.md`

## Global Constraints

- Work only on `main`.
- Keep `ProjectComposition` as the only renderer.
- No server rendering or cloud rendering.
- Project aspect ratio and frame rate are project-level.
- Export resolution/quality are export-only.
- OPFS for projects >= 60 seconds, arraybuffer fallback.
- Keep R1-R5 green.
- Run focused tests per task, then `npm run check:all`, dev E2E, and production E2E before Gate G10.
- File names must be sanitized before download.

## Review Focus

- 720p dimensions for every aspect ratio.
- FPS changes do not resample scenes.
- Capability fallback when MP4 is unsupported.
- Output target changes at the 60-second boundary.
- Cancellation never exposes a download or mutates the project.
- Validation rejects the wrong container, dimensions, duration, or missing audio.
- OPFS failures fall back safely.
- R1 export labels and WebM flow remain intact.
